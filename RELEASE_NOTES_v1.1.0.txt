# 🚀 Koda Dev v1.1.0: Full IDE Code Editor & Liquid Glass Design

> **Koda Dev v1.1.0** is our largest milestone yet! This release transforms Koda Dev into a complete mobile IDE with a built-in multi-tab code editor, debuts the **Apple-inspired Liquid Glass design system** with hardware backdrop blur and AGSL lens refraction, introduces an **in-workspace terminal sheet**, real-time **context window meter & auto-compaction**, and **live mid-run agent steering**.

---

## 🌟 Highlights

### 📝 Full IDE Code Editor
- **Multi-Tab Workspace**: Open, edit, and switch between files with tab state indicators and quick close actions.
- **Synchronized Gutter & Syntax**: Clean monospace coding canvas with synchronized line number gutters.
- **Mobile Accessory Bar**: Fast access to essential code syntax symbols (`{ }`, `( )`, `;`, `->`, `=`, `[ ]`, `"`, `'`, `$`).
- **Responsive Split View**: Seamless transition between single-pane mobile view and dual-pane split view on landscape and large screens.
- **File Explorer**: Integrated file tree, breadcrumbs, search, and new file/folder management.

### 💎 Liquid Glass Design System
- **Hardware Optics**: Hardware-accelerated `RenderEffect` backdrop blur, AGSL signed distance field (SDF) lens refraction, and internal specular highlight sheens.
- **Floating Capsule UI**: Floating TopAppBars, docked bottom navigation bars, and unified input capsules with frosted micro-glass cards.
- **Tactile Physics**: Interactive spring-press animations (`springPressClickable`) matching modern physical fluid design.
- **Dynamic Edge-to-Edge**: Full system bar insets and translucent navigation bars across all Android 8.0–15+ devices.

### 💻 In-Workspace Terminal Bottom Sheet
- **Instant Linux Terminal**: Slide-up Ubuntu 24.04 PRoot terminal accessible right from Chat and Editor without losing your flow.
- **Keyboard-Aware Elevation**: The terminal dynamically lifts above the soft keyboard and supports multi-session tabs.
- **Frosted Accessory Keys**: Ergonomic keys (`ESC`, `TAB`, `CTRL`, `CTRL-C`, arrow keys, pipe `|`).

### 🧠 Autonomous Agent Upgrades
- **Real-Time Context Window Meter**: Live token gauge inside the input capsule displaying active memory consumption (e.g. `22k/256k`).
- **Autonomous Auto-Compaction Guard**: Proactively compacts conversation history at 80% capacity to prevent LLM context blowouts.
- **Live Mid-Run Steering**: Provide guidance or adjust agent direction mid-generation without cancelling the session.
- **Interactive Diff Review**: In-chat inline diff cards and bottom sheet diff inspector for visual code review before saving to disk.
- **Foreground Service Host**: Unbounded agent runs protected with CPU wake locks against Android OS background kills.
- **Command Timeline & Log Truncation**: Explicit command execution display in the activity timeline with expandable "Show more" logs.

### 🤖 AI Providers & Connectivity
- **Koda Community Free (Keyless)**: Out-of-the-box free AI provider (Kilo Free) pre-configured with zero setup required.
- **Official NVIDIA NIM Integration**: Instant access to fast Nemotron reasoning and vision models.
- **Antiroute QR Scanner**: 1-tap CameraX QR code pairing for local Ollama / Antiroute tunnels.
